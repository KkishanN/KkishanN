# Kishan Nadageri — Software Engineer Portfolio

A clean, minimalist, single-page portfolio highlighting enterprise engineering experience, cloud architecture, and open-source GitHub projects.

Built with **React 18**, **TypeScript**, **Vite**, and **Tailwind CSS**.

---

## ⚡ Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build optimized production bundle
npm run build
```

Local server runs at: `http://localhost:5173/`
